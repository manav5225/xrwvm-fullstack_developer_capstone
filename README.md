# Cars Dealership - Full-Stack Capstone Project

**Repository name:** xrwvm-fullstack_developer_capstone
**Project name:** Cars Dealership - Full-Stack Capstone Project

A full-stack web application for a national car retailer where users can browse dealerships, view dealer details, and post reviews with sentiment analysis.

**Tech stack:** React, Django, Node.js/Express, MongoDB, Flask, SQLite, Docker, Kubernetes, IBM Cloud Code Engine
